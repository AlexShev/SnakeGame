# SnakeGame

Консольная «Змейка» на C++ для Windows. Доступны ручная игра и три уровня бота:
лёгкий следует заданной траектории, средний ищет путь к еде, сложный пересчитывает
путь каждый ход и учитывает доступное пространство, чтобы избегать ловушек.

## Запуск

1. Установите Visual Studio с компонентами «Разработка классических приложений на C++»,
   MSVC v143 (Visual Studio 2022) и Windows SDK.
2. Откройте `pyton.sln`, выберите конфигурацию `Debug | x64` и нажмите `Ctrl+F5`.
3. Выберите сложность и тип игрока. В ручном режиме используйте стрелки или WASD;
   Escape завершает партию.

Игра использует Windows API для управления консолью и клавиатурой.

## Проверка игровой логики

Проверки в `tests/CoreTests.cpp` не требуют Windows API. Например, с установленным
компилятором g++ их можно запустить командой из корня репозитория:

```sh
g++ -std=c++14 -O2 -I. tests/CoreTests.cpp pyton/Field.cpp pyton/Snake.cpp pyton/AverageArtificialGamer.cpp pyton/HardArtificialGamer.cpp -o core-tests
./core-tests
```

Для сборки в Windows через Visual Studio используйте файл решения: тестовый код
не включён в игровой проект.
