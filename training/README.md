# Экспериментальный нейробот

Это небольшая сеть 21 → 32 → 4, обучаемая с учителем на ходах алгоритмического бота третьего уровня. Веса хранятся в `models/neural_weights.txt`; при запуске игры Python и NumPy не нужны. Модель пока исследовательская: совпадение с учителем на отложенных состояниях около 80%, но в самостоятельных партиях она часто погибает от голода. Не используйте точность классификации как оценку качества игры.

## Обучить повторно

Из корня проекта при наличии C++14 и Python с NumPy:

```bash
g++ -std=c++14 -O2 training/collect.cpp pyton/Field.cpp pyton/Snake.cpp pyton/HardArtificialGamer.cpp -o collect
./collect 25 > samples.csv
python training/train.py samples.csv models/neural_weights.txt
```

`collect` запускает реальные `Field` и `Snake` без вывода и задержки, а `train.py` сохраняет новый файл весов. CSV с партиями в репозиторий добавлять не нужно. Для честной оценки нужны отдельные партии с фиксированными начальными состояниями и сравнение с алгоритмическим ботом; запуск Windows следует проверить отдельно.

В игре выберите третий уровень и тип игрока `3 - neural bot`. Файл весов ищется в `models/` относительно рабочего каталога или в `../models/` при запуске из папки проекта Visual Studio. Если файл не найден, используется алгоритмический бот.
